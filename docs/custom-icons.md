# 自訂圖示選單

從「圖示」選單上傳 PNG／WebP 時，Juice 會在白板上放入圖示，並將它加入該白板選單的「我的圖示」，供之後重複插入。舊白板中已放置的自訂圖示也會顯示於選單；從選單再次插入時會保存到圖示庫。

圖示庫跟著**目前白板**保存，包含在白板 JSON 匯出與已啟用的 Drive／本機同步檔中，不會自動跨白板或跨瀏覽器共用。上傳的圖示會轉為最多 256 像素的 PNG 內嵌資料；白板上的每個圖示仍保留自己的 `src`，所以刪除白板上的圖示不會移除已保存的圖示庫項目。圖示庫保存在根物件 `iconLibrary`，每項有 `id`、`label`、`src`；舊白板沒有此欄位時仍可正常讀取。圖示庫最多 30 項、內嵌圖像合計 6 MB，白板整體仍受原有匯入與瀏覽器容量限制。

使用舊版前端重新儲存含圖示庫的白板，舊版 normalize 會丟失 `iconLibrary`。重要白板更新前先匯出 JSON 備份。
