# JUICE-UI-008｜卡片摘要與聚焦模式

Workspace 可從 `nested-cards.html` 或 `workspace.html` 進入；本功能先在本機驗收，再隨版本發布。

頁首「白板密度」可選概覽、摘要、詳細。概覽保留容器名稱、唯一工作數與簡短狀態摘要；摘要展開各層，工作只顯示名稱、負責人與既有狀態底色；詳細沿用原本的展開狀態與可編輯欄位。工作狀態與階段範圍仍可由卡片提示查看，表格與卡片選單保留編輯能力。

選取卡片後可從「⋮ → 此卡顯示」設定單張卡片；容器設定會沿用到子卡，子卡仍可再個別調整。容器上的「聚焦」會展開該分支的詳細內容，其他分支保留概覽或摘要；按「退出聚焦」恢復原先密度。展開時仍依既有避讓規則從基準座標計算，退出後恢復布局。

密度、單張顯示方式與聚焦是本次頁面的暫時顯示設定，重新整理後回到詳細模式；切換不改原型 JSON、工作資料、引用關係或 Classic 儲存。原本的展開狀態仍由既有 `ui.expanded` 保存。「全部收合」會切換概覽、退出聚焦，並收合既有展開狀態。

本機驗收：切換摘要後檢查 OMG 四層與共用工作；聚焦「異動」並退出，確認其他分支及基準位置復原；在詳細模式修改狀態與負責人後重新載入，確認工作表格與兩處引用同步。
