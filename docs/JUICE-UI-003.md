# JUICE-UI-003｜資料檢視、引用管理與條件著色

本機原型，分支 `codex/juice-ui-003-data-views`，基於正式版 UI-002 的 `dce6452`。未推送、未合併、未部署；正式站仍是 UI-002。

## 直接操作

在專案根目錄執行 `python3 -m http.server 4200 --bind 127.0.0.1`，開啟 `http://127.0.0.1:4200/nested-cards.html?ui=003`。

1. 展開 OMG → 異動 → 工作清單，再展開「驗收準備」。工作卡的實線／◆ 是主要歸屬，虛線／↗ 是引用。
2. 點卡片名稱選取，再開「⋮」。第一層已有名稱輸入欄，按「套用名稱」或 Enter，沒有第二個改名視窗。工作說明等完整資料仍沿用原地詳情。
3. 同一選單可選主要歸屬，從既有容器關係或畫布位置中擇一，也可選資料庫歸屬。沒有為了表示原始物件而新增空白處的卡片。
4. 右側預設工作表格，只列每項工作一次。直接編輯狀態、負責人、期限、階段範圍；清空負責人／期限表示待確認。負責人按 Enter 或離開欄位套用。
5. 「結構清單」顯示每個位置的階層、用途、主要歸屬與引用。此視角不是工作統計，重複列仍共享 ID。切換視角不複製資料。
6. 拖動白板與清單之間的分隔線調寬，也可聚焦分隔線後按左右方向鍵。「全畫面／返回右側」、「隱藏清單」都不改卡片座標。
7. 點清單名稱會定位相應白板卡片，必要時展開上層容器。全畫面清單會先回到畫布。未放置的資料只提示如何引用，不強制產生卡片。
8. 工作表格可搜尋名稱／說明、篩選負責人／狀態／階段範圍、排序，並設定顯示欄位。所有工作總數皆去重；篩選只改呈現。
9. 按「顏色規則」調整五種狀態的名稱與色彩，也可匯入／匯出獨立 JSON 規則。底色仍由手動顏色控制，狀態僅用色條及文字呈現。
10. 按「儲存原型」後重新整理；資料、主要歸屬、規則、清單寬度／視角／篩選／欄位設定可恢復。也可下載完整原型 JSON 備份。

## 最小資料增量

| 位置 | 新增內容 |
|---|---|
| `objects[].primary` | 唯一主要歸屬，`{kind:membership,id}`、`{kind:placement,id}` 或 `{kind:library}`；ID 指向既有關係，不複製物件。 |
| `objects[].scope` | 可選 `in`／`out`／null，與狀態無關。容器範圍不自動推定子工作範圍。 |
| `colorRules` | version 1，五種狀態各含 label／安全 HEX 色碼。預設來自 `assets/nested-color-rules.js`，調整後隨原型保存。 |
| `ui.list` | 顯示、寬度、全畫面、工作／結構視角、欄位、排序、篩選及結構收合路徑。 |

仍是 `juice-nested-board` version 1，保留既有物件與關係 ID。舊檔沒有主要歸屬時，先選第一個既有畫布位置，否則第一條容器關係；這只是技術預設，不推測專案責任。使用者可從選單更正。若完全未放置，歸屬資料庫，仍可在工作表格編輯。

刪除主要位置後，會指派至其他既有位置；只有既有 UI-002「移除最後一處巢狀位置」才沿用原本移至畫布的保護行為。刪除原始物件與移除引用仍分開確認。引用整個容器也會引用其結構；在任何位置修改該容器的子關係，會同步影響它的其他呈現位置。

主要位置沿父容器的主要位置判定：在引用容器下看到的子樹也顯示為引用。父卡工作彙整使用唯一工作 ID 集合，僅顯示工作數與狀態分布，沒有功能完成率。

## 三階段實作界線

- 資料：在既有 nested-core 補歸屬驗證、修復與去重彙整；既有 board 原始副本完全保留。
- 視角：新增 nested-views 模組，接到同一份記憶體狀態，不另存工作。既有畫布與卡片互動仍在 nested-app。
- 著色：獨立預設規則檔；狀態色條、手動底色、階段符號分開，不互相覆寫。

存檔仍僅在明確操作時使用 `juice-nested-prototype-v1`，不接觸正式白板 localStorage、IndexedDB 或 Google Drive。開啟與驗證只在記憶體補預設，不會自動覆寫舊存檔。修改前可先下載 JSON。

## 限制與後續

- 另開瀏覽器視窗已評估，但未實作：目前沒有共享編輯交易或即時衝突處理，不應讓兩個視窗各自覆蓋未保存狀態。先用同頁全畫面；未引入多視窗同步或多人共編。
- 「主要歸屬」是物件收納關係，不等於負責人或權限。移動歸屬目前從既有位置選擇；若要改到新容器，先引用，再指定主要歸屬。
- 不提供卡片種類互轉、正式格式遷移、完整 PM 或功能完成率。
- 桌面清單停駐右側；窄螢幕停駐下方，可隱藏或全畫面。表格較寬時可水平捲動或調整欄位。
- 結構最多顯示前 500 個位置並提示上限；工作表格仍讀取完整物件集合。保留既有 200 物件、400 關係、8 層等安全上限。
- 桌面 Chromium 與模擬觸控／窄螢幕已納入測試，尚未驗收 Safari 或手機實機。
