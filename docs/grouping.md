# 白板物件群組

在白板工具列開啟「框選」，拖出選取範圍，或按住 Shift 逐一選取卡片、圖片、圖示與自由文字。選到至少兩個物件後，在「更多工具」選「建立群組」。圖片在框選模式下可直接選取；平常仍遵循原有的圖片編輯／鎖定操作。

建立後會自動離開框選模式。拖曳群組標題或可拖曳的成員可一起移動；圖片若仍在鎖定模式，請拖曳群組標題。群組標題旁的「解開群組」只移除群組關係，保留全部物件與白板卡片連線。右鍵群組也有「解開群組」。按 Delete 刪除已選群組時同樣只解開群組。

新群組在原有 `groups` 項目增加 `members: [{type,id}]`，`type` 為 `card`、`image`、`icon` 或 `note`。成員以 ID 明確指定，不會因其他物件剛好進入群組框而一起移動。`schemaVersion` 維持 3；沒有 `members` 的舊群組仍可讀取，並沿用原先依位置移動框內卡片的行為。匯入時會檢查成員存在與否，避免無效參照造成靜默資料損失。
