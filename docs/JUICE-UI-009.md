# JUICE-UI-009｜自由布局與緊湊布局切換

本機 Workspace 新增「自由布局／緊湊布局」切換，預設仍為自由布局。緊湊布局以卡片實際寬高、目前畫布可用寬度與縮放比例計算多欄排列；概覽、摘要、詳細及單卡聚焦都使用同一套呈現座標。原始位置不變，跨類型連線跟隨呈現座標重畫。

布局偏好僅存於原型的可選 `ui.layout`（`free` 或 `compact`）；舊原型無此欄位時視為自由布局。緊湊布局停用手動拖曳；切回自由布局後可再次編排。工作、引用、來源白板與 Classic 儲存不變。

後續優化：緊湊概覽下，若容器的任一層子工作屬於本期範圍，標題列會顯示旗子；引用共用相同判斷，且工作總數持續顯示。緊湊布局固定每張根卡的欄位，展開只推動同欄下方卡片，不讓其他欄跳位，也不修改手動座標或工作資料。

[本期範圍插旗畫面](ui009-scope-flag.png) 取自本機 OMG 全功能地圖副本；只有確實含有本期範圍工作的功能顯示旗子。
